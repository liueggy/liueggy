## 👋 Hi, I'm LiuEggy

我是一名 **机械工程专业本科生**，长期关注嵌入式控制、机器人系统与工程自动化。  
我喜欢把一个系统从结构、电路、底层驱动、通信协议，一路做到上层控制和可视化，让它真正稳定地跑起来。

> **目标不是只写能运行的代码，而是构建可调试、可维护、可迭代的工程系统。**
